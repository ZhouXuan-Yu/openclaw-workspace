## 【开发者避坑】直接影响工作流的变化

- **多工具栈成默认姿态**：Claude Code（primary 28%）、Cursor（24%）、Copilot（17%，在掉）——别再押注单一工具，编辑内联 + agent 重构分工最划算。
- **MCP/A2A 是护城河也是迁移成本**：新项目应原生支持 MCP；旧 AutoGen/Semantic Kernel 项目进入迁移窗口（仅维护/安全补丁）。
- **个人 Agent 的跨应用权限**：因权限开放被部分 App"封禁"，企业需把数据权限细化到"哪类任务可调哪些数据、异常谁来接管"，并把高风险增删改查放进可控制/可回滚/可审计沙箱。
- **Agent 改了推理成本模型**：指标从单次 token 速度转向冷启动、缓存、扩缩容、整体成本；关注 KV Cache 压缩与峰谷定价（如 DeepSeek API），做成本波动预案。
- **选型按场景而非榜单**：开源闭源差距缩到 3-6 个月、新模型发布频率激增；按 agentic/coding 实测选型。
- **AI 生成内容有品牌合规风险**：企业开始禁 AI 生成物料（沃尔玛），出海/品牌团队要先立规。
- **安全重点：prompt injection**。Agent 自主度越高，注入攻击后果越大，务必加审计与回滚。
