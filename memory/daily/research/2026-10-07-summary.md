## 【开发者避坑】直接影响工作流的变化

- **长上下文靠架构而非堆显存**：MLA 压缩 KV cache、稀疏注意力（DeepSeek NSA、月之暗面 MoBA）、混合 Mamba-Transformer（NVIDIA Nemotron 3 Super，1200 亿总参/120 亿激活）成为主流解法。选型时看"单位 token 成本与吞吐"，别只盯参数量。
- **端侧/本地部署门槛显著下降**：192GB 统一内存可本地跑 284B 的 DeepSeek V4 Flash（约 15 tok/s）；Q4 量化下 Qwen3.5-122B 约 24.7 tok/s。Ollama / vLLM / LM Studio 是标准栈——数据敏感场景优先本地。
- **Agent 生产化必备两件套**：① 可观测性（决策轨迹 + 模型置信度 + 评估管线，参考 New Relic/OpenTelemetry）；② 高影响动作强制人工审批/隔离账户（Robinhood 的专用账户、Realtor 的复核后发送都是范例）。
- **沙箱出网安全**：给 Agent 独立执行环境时，用零信任出网代理注入凭证，别把 token 暴露给不受信代码（Cloudflare Outbound Workers 模式）。
- **模型迭代极快**：本周新增 7 个模型（Ling 3.1 Flash / GPT-6.1 Sol / Claude Sonnet 5.5 等），保持多供应商 + 自动 failover 策略，勿硬绑单一闭源模型。
