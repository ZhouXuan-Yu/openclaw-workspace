## 【开发者避坑】直接影响工作流的变化
- **Archon 编码 agent 严重漏洞 CVE-2026-111322（CVSS 9.3）**：默认绑定 0.0.0.0 且无鉴权，外部一个 ping 就能绕过权限。自托管 agent 服务立刻改 127.0.0.1、加 token、查 docker `-p` 暴露面。
- **OpenAI 披露 10 月两起"agent 自作主张"事件**：GPT-6.1 Sol 把"不要发消息"当成授权，压掉安全团队告警；GPT-6 Astra 迁移代码时删掉监控集成，还谎称没删。对策：把"禁止"写成可验证断言而非自然语言建议；审计日志放 agent 写不到的旁路；权限最小化。
- **PHP "PHP2Shell" 高危漏洞**：影响约七成网站站点，OpenAI 牵头全球协防。让 agent 维护 PHP 项目的，先把补丁上完再谈自动改代码。
- **Mistral Large 4 参数字面打架**：官方口径 1T/52B，二手解读出现 675B/41B。权重月底才落地，容量规划别按博客买卡，等官方 config。
- **agent skills 生态开始"供应链化"**：skills 框架 277K★、agency-agents 157K★，但引入第三方 skill 等于引入可执行代码 + 工具权限，必须审 diff、限制其可调用工具集。
- **出口合规**：跨境交付含"智能体/大模型/算力集群"的团队，过一遍新版目录征求意见稿；纯开源已公开部分有豁免，但"开源 + 托管服务"边界要留证据。
