# 每日深度调研工作流（Q0 双通道管线）

触发器: cron `0 16 * * *` (Asia/Shanghai) — 每日新闻

## 完整流程

```
┌─────────────────────────────────────────────────────────┐
│  0️⃣  前置：清代理环境                                    │
│  $env:HTTP_PROXY=''; $env:HTTPS_PROXY=''; $env:NO_PROXY='*' │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  1️⃣  管线健康检查                                       │
│  python tools/daily-research/pipeline.py --health        │
│  → 读取 pipeline-health.json（自进化路由表）               │
│  → 输出哪些后端可用/不可用                                 │
│  → 读取 news-pending.json（待恢复队列）                    │
│  → 如有待恢复日期 → 补简短摘要 + mark_recovered            │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  2️⃣  Track A: 社会监听（多平台）                         │
│                                                          │
│  web_search("AI Agent 最新进展", 5条)                     │
│  web_search("智能体 大模型 热点", 5条)                     │
│  web_search("LLM 架构演进 2026", 5条)                      │
│  web_search("开源项目 AI Agent", 5条)                     │
│  web_fetch(热门链接) — 选 2-3 个深度阅读                    │
│                                                          │
│  → 整理结果 → pipeline.py --save-websearch（持久化）       │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  3️⃣  Track B: 深度研究                                   │
│                                                          │
│  海外动态: web_search("AI Agent this week 2026", 3条)     │
│  技术前沿: web_search("new LLM model release", 3条)       │
│  开源雷达: web_search("GitHub trending AI", 5条)           │
│                                                          │
│  → 整理结果 → pipeline.py --save-websearch（追加）         │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  4️⃣  YouNavi 深度研究（可选，不稳定）                    │
│                                                          │
│  尝试: python -c "from younavi_bridge import YouNavi;     │
│                   yn = YouNavi();                         │
│                   yn.research_plan_only('AI Agent 2026')" │
│  如果成功 → 摘取关键洞察                                  │
│  如果失败 → 跳过，不影响主流程                             │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  5️⃣  交叉验证 + 去重                                     │
│                                                          │
│  pipeline.py --summary 读取所有采集数据                    │
│  检查重复来源、合并相近主题                                 │
│  记录去重结果到摘要                                       │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  6️⃣  报告生成                                           │
│                                                          │
│  角色: AI 行业观察家 + 技术架构师                          │
│  整合: Track A（社会面）+ Track B（深度）+ 待恢复摘要       │
│                                                          │
│  格式:                                                    │
│  【速览】5 个 Agent 方向大事件                             │
│  【速览】5 个世界范围大事件                                │
│  【开发者避坑】直接影响工作流的技术变化                      │
│  【开源项目雷达】本期值得关注的项目                         │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  7️⃣  推送                                               │
│                                                          │
│  微信: delivery.announce（自动，框架层推送）               │
│  飞书: 无（单 delivery 限制，后续可加转发 cron）            │
└─────────────────────────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────┐
│  8️⃣  收尾                                               │
│                                                          │
│  如果因网络错误失败:                                       │
│    python tools/task-recovery/news_pending.py mark_failed │
│    生成简短报告推送                                      │
└─────────────────────────────────────────────────────────┘
```

## 数据目录

```
memory/daily/research/
├── YYYY-MM-DD-health.json      # 健康检查结果
├── YYYY-MM-DD-websearch.json   # web_search 采集结果
├── YYYY-MM-DD-younavi.json     # YouNavi 研究结果
├── YYYY-MM-DD-social.json      # 社会监听结果
└── YYYY-MM-DD-summary.md       # 采集摘要
```

## 超时控制

总超时: 600s (10分钟)
- 健康检查: ~5s
- Track A web_search ×8: ~120s
- web_fetch ×3: ~60s
- Track B web_search ×4: ~90s
- YouNavi（尝试）: ~60s（超时则跳过）
- 报告生成: ~120s
- 推送: ~10s

## 失败处理

| 失败点 | 处理 |
|--------|------|
| 模型 API 不通 | fallback → my/deepseek-v4-flash |
| 都断 | news_pending.py mark_failed → 生成简短报告 |
| web_search 部分失败 | 跳过失败关键词，用其他关键词继续 |
| YouNavi 不可用 | 跳过，不影响主流程 |
| 管线健康文件不存在 | 视为正常（首次运行） |
